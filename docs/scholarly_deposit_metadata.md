## Abstract

English learners often make mistakes about verb-noun collocations. Through the
analysis of verb-noun collocation errors in CLEC, this paper proposes a model
to correct these mistakes made by Chinese learners. A verb-noun collocation
library is built first, then a similarity measure is used to retrieve a coarse
set of similar collocations. Classification filters candidates that do not fit
the sentence context, and a language model ranks the remaining correction
suggestions. Experiments on test data constructed from the BNC corpus show that
combining similarity inference and contextual features is effective for
correcting verb-noun collocation errors.
